## COMO PUBLICAR DE GRAÇA NO GITHUB PAGES

1. Entre no github.com com sua conta e abra  https://github.com/new

2. Crie o repositório:
     - Repository name:  solucoes-dependencia-quimica
     - Marque: Public
     - NÃO marque "Add a README file" nem .gitignore (deixa tudo vazio!)
     - Clique em  Create repository

3(abertura não costuma pedir nada). No Prompt de Comando (cmd), cole:

     cd %USERPROFILE%\Documents\solucoes-dependencia-quimica
     git remote add origin https://github.com/SEU-USUARIO/solucoes-dependencia-quimica.git
     git push -u origin main

   → troque SEU-USUARIO pelo seu nome de usuário no GitHub
   → aparecerá uma janelinha do GitHub pra entrar e autorizar: autorize

4. Depois do push concluído, no GitHub:
     Repositório → Settings → Pages
       Source/Branch:  main   |   pasta:  / (root)
     → Save

5. Espere 1–2 minutos. O site fica aqui:
     https://SEU-USUARIO.github.io/solucoes-dependencia-quimica/
